# Wave field reconstruction and forecasting from sparse buoy data using machine learning

This repository contains the code used in an article currently under revision by Vidal et al. (2026): "Wave field reconstruction and forecasting based on sparse buoy data using machine learning techniques."

## Contents

- `train_nn.py` – Training scripts for MLP, LSTM-MLP, and LSTM-CNN models
- `test_nn.py` – Evaluation and testing of trained models
- `dataset_prepare.py` – Data preparation and preprocessing
- `dataset_aux.py`, `classes.py`, `piml_aux.py` – Auxiliary classes and functions
- `postprocessing.py` – Postprocessing and visualization utilities

## Requirements

Dependencies are standard scientific Python packages (NumPy, PyTorch, pandas, xarray, scikit-learn, etc.).

## Usage

1. Prepare the data in the `data/` directory (see `data/README.txt`).
2. Train models using `train_nn.py`.
3. Evaluate using `test_nn.py`.
4. Post-process results using `postprocessing.py`.

## Data

ERA5 swell data can be downloaded directly from the [Copernicus Climate Data Store](https://cds.climate.copernicus.eu/), or by contacting the authors.

## Models

Trained weights and logs are generated by the scripts and are not stored in this repository (see `weights/README.txt` and `logs/README.txt`).
